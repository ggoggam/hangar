# Security

Hangar holds a Fly.io token that can read, and for a full login also change, your apps. Please
report anything that could expose it or other account data privately, through
[GitHub's private vulnerability reporting](https://github.com/ggoggam/hangar/security/advisories/new),
not in a public issue.

Include what's affected, how to reproduce it and the platform and version. Leave real tokens out
of the report: a description of what leaks is enough.

Problems with Fly.io itself, rather than with this app, go to
[Fly.io's security team](https://fly.io/docs/security/).
